## Corner plot comparison
- Provided are corner plots for simplified PE (top) and the full PE (using marginalized phase model) for various eccentric binary sytems.
- In simplified PE we vary only $\mathcal{M}\_c, q$ and $e_{10}$.
- In full PE we vary $\mathcal{M}\_c, q, e_{10}, s_{1z}, s_{2z}, d_{L}$
- The file names represent the mchirp and the $e_{10}$ (separated by \_) of the simulated injection signal.
- The subdirectory _/varying_sky_polarization_comparison_ contains a comparison plot where we vary also the sky and polarization angle.
